### 关键知识点
- HarmonyOS 沉浸光感 = `systemMaterial` 通用属性 + `uiMaterial.ImmersiveMaterial`（来自 `@kit.ArkUI`）
- HDS 组件（HdsTabs/HdsNavigation）通过 `systemMaterialEffect` 参数配置，但 tabBar 只支持字符串标签
- 普通 Tabs 可直接用 `.systemMaterial()` 通用属性，配合 `barBackgroundColor(Color.Transparent)` 让材质透出
- API 26+ 的 build-profile 版本号必须用字符串格式 `"26.0.0"`，API 10-25 用数字格式
- `deviceInfo.sdkApiVersion`（不是 apiVersion）用于运行时 API 版本检测

## 沉浸光感第三次修正 — barFloatingStyle 方案

### 背景
- 用户第三次指出实现不对，要求参考 HDS 文档使用 HdsTabs
- 调研发现：`@kit.UIDesignKit`（HDS 组件 HdsTabs/hdsMaterial）**不在 OpenHarmony SDK 中**，仅 HarmonyOS SDK 可用
- 当前项目 `runtimeOS="OpenHarmony"`，SDK 路径 `~/Library/OpenHarmony/Sdk`（14/20/23/26.0.0），无 HarmonyOS SDK
- OpenHarmony SDK 26.0.0 中的 kits 目录不含 `@kit.UIDesignKit.d.ts`

### 最终实现方案
1. **`ImmersiveHelper.ets`**（重写）：
   - 使用 `uiMaterial` from `@kit.ArkUI`（非 `hdsMaterial` from `@kit.UIDesignKit`）
   - `deviceInfo.sdkApiVersion >= 26` 检测（非 23，因为 uiMaterial since 26.0.0）
   - `material` getter 返回 `uiMaterial.ImmersiveMaterial | undefined`
   - 创建 `new uiMaterial.ImmersiveMaterial({ style: ImmersiveStyle.THICK, interactive: true })`
2. **`Index.ets`**（重写）：
   - 两套 `@Builder`：`buildImmersiveTabs()` 和 `buildNormalTabs()`
   - 沉浸版：`Tabs` + `.barFloatingStyle({ barBottomMargin: 0, systemMaterial: this.immersiveMaterial })` + `.barOverlap(true)` + `.barBackgroundColor(Color.Transparent)`
   - 回退版：`Tabs` + `.barBackgroundColor(AppColors.CARD_BG)`
   - `build()` 中 `if (this.useImmersiveTabs) { this.buildImmersiveTabs() } else { this.buildNormalTabs() }`
   - 两个 builder 共用 `tabItemBuilder(index)` 自定义 Tab 样式
3. **关键修正**：前次 `.systemMaterial(ImmersiveMaterial)` 直接调用在 `CommonMethod` 上接受 `SystemUiMaterial`（类型不匹配），导致无效；正确方式是通过 `FloatingTabBarStyle.systemMaterial` 字段传入 `ImmersiveMaterial`（类型匹配）

### 编译结果
- `hvigorw assembleHap` BUILD SUCCESSFUL，0 错误
- WARN：`barFloatingStyle` since 26.0.0，compatibleSdkVersion=14（预期，运行时检测处理）

### 如需 HDS 组件
- 用户需在 DevEco Studio SDK Manager 中安装 HarmonyOS SDK（非 OpenHarmony）
- 安装后 `@kit.UIDesignKit` 可用，可改用 `HdsTabs` + `hdsMaterial.MaterialType.ADAPTIVE` + `hdsMaterial.MaterialLevel.ADAPTIVE`（API 23+）
